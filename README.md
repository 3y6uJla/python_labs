# Лабораторная работа №1

## Примеры запуска

### Задание 1. greetings

Файл: `src/lab01/01_greetings.py`

Пример запуска:

```text
$ python src/lab01/01_greetings.py
in:
Имя: Илья
Возраст: 18
out:
Привет, Илья! Через год тебе будет 19.
```

### Задание 2. sum&avg of 2 num

Файл: `src/lab01/02_sum_avg.py`

Пример запуска:

```text
$ python src/lab01/02_sum_avg.py
in:
a = 22
b = 33
out:
sum=55.00; avg=27.50
```

### Задание 3. Скидка и НДС

Файл: `src/lab01/03_discount_vat.py`

Пример запуска:

```text
$ python src/lab01/03_discount_vat.py
in:
price: 1000
discount: 10
vat: 20
out:
База после скидки: 900.00 ₽
НДС:               180.00 ₽
Итого к оплате:    1080.00 ₽
```

### Задание 4. Перевод минут в ЧЧ:ММ

Файл: `src/lab01/04_minutes_to_hhmm.py`

Пример запуска:

```text
$ python src/lab01/04_minutes_to_hhmm.py
in:
Минуты: 135
out:
2:15
```

### Задание 5. Инициалы и длина ФИО

Файл: `src/lab01/05_initials_and_len.py`

Пример запуска:

```text
$ python src/lab01/05_initials_and_len.py
in:
ФИО: Осмаков Илья Александрович
out:
ОИА.
26
```

### Задание 6. larp vs pro

Файл: `src/lab01/06_larp_vs_pro.py`

Пример запуска:

```text
$ python src/lab01/06_larp_vs_pro.py
in:
Введите кол-во перваков: 3
Максимов Максим 18 True
Геннадьев Геннадий 17 False
Алексеев Алексей 17 True
out:
2 1
```

Программа определяет количество пользователей по определенному флагу.

### Задание 7. Cyberleek

Файл: `src/lab01/07_cyberleek.py`

Пример запуска:

